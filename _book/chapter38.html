38.1 chunk

R markdownでRのコードを書くときには、chunkというものを用います。QuartoでもR markdownと同じく、chunkを用いてスクリプトを書きます。chunkではbacktick3つ（```）の後にプログラミング言語の名前（Rの場合はr）を中括弧の中（{}）に記載します。次の行以降にRのスクリプトを書き、最後にbacktick3つ（```）を記載します。backtickの間のコードはQuartoをRenderする際に実行されます。

chunk
```{r}
# この間にコードを記載する
a <- c(1, 2, 3, 4, 5)
a
```
# この間にコードを記載する
a <- c(1, 2, 3, 4, 5)
a
## [1] 1 2 3 4 5

chunkはRだけではなく、Python、Markdown、前章で説明したMermaidやGraphvizなどを用いる場合にも使用します。

Pythonを実行する
```{python}
a = [1, 2, 3, 4, 5] # リスト（Rにはない記法）
print(a)
```
a = [1, 2, 3, 4, 5] # リスト（Rにはない記法）
print(a)
## [1, 2, 3, 4, 5]
Pythonの実行

上記のように、PythonのchunkがRのQuartoに含まれている場合には、reticulateパッケージ(Ushey, Allaire, and Tang 2025)（reticulated python、Malayopython reticulatus、和名：アミメニシキヘビより）により、Pythonのコードが実行されます。reticulate::repl_python関数を実行すると、コンソールの記号が>>>に変化します。この記号が出ているときには、コンソールはPythonを実行するモードになっています。exitでPython実行モードからRの実行モードに戻すことができます。

Markdownのchunk
```{markdown}
![](.image/toba.jpg)
```
![](.image/toba.jpg) # 変換されず、そのまま表示される

Rstudioでは、Ctrl+ALT+ICtrl+ALT+Iのショートカットで文章にチャンクを挿入することができます。

38.2 chunk option

R markdownの章で説明した通り、chunkにはchunk optionと呼ばれる、chunk実行時の設定を変更することが出来る機能があります。chunk optionはchunkの{}の中に以下のように記載し、用います。

chunk optionの利用
```{r, eval = FALSE}
# eval = FALSEはコードを実行しない際のchunk option
knitr::kable(iris[1:2, ])
```
# eval = FALSEはコードを実行しない際のchunk option
knitr::kable(iris[1:2, ])

R markdownの章に示した通り、主なchunk optionには以下のようなものがあります。また、Rを用いる場合には、chunk optionとして、R markdownのchunk optionを用いることができます。詳しくはDr. Yihui Xieが作成されているページをご参考下さい。

オプション名 意味
echo コードを表示するかどうか
error エラーで停止するかどうか
eval コードを評価するか
messagee メッセージを表示するか
warning warningを表示するか
results 結果の表示方法の指定
fig.align 図の位置（“center”など）
fig.width 図の幅
fig.height 図の高さ
out.width 図の出力時の幅調整
collapse コードと結果の折り畳み
filename チャンク名の設定

例えば、ライブラリの読み込み時にメッセージが出る場合（tidyverseは読み込み時に必ずメッセージを表示します）にはmessage=FALSEを設定することで、メッセージがRender後に表示されないようにすることができます。エラーが出る処理を出力したいのであればerror=trueを、Rでの演算を実行したくない場合はeval=FALSEを、Rのスクリプトを表示したくない場合にはecho=FALSEを設定するとよいでしょう。

また、このテキストでのchunkにはほぼすべてfilenameが設定されており、Rのコードにはほぼ必ずタイトルがついていると思います。

38.2.1 chunk optionの記載位置について

このchunk optionについては、Quartoでは大幅に拡張されています。例えば前章で説明したレイアウトに関しては、chunk optionに記載することでも対応ができるようになっています。

chunk optionが拡張されたことで、{}の中にたくさん記載すると読みにくく、管理しにくくなるため、Quartoでは以下のように、#|の後に記載し、chunk optionを設定できるようにされています。この場合、=を用いて指定していた値は、YAMLのように:を用いて記載します。

chunk optionをchunk内で宣言する
```{r}
#| message: false
#| column: margin

plot(cars)
```
chunk optionで.column-marginを設定し、右にアウトプットを表示
plot(cars)

columnに設定する幅には、marginの他にbody、page、screenの3つに加えて、-outset、-insetの2種、-right、-leftの2つを後につけることで、表示する幅をコントロールすることもできます。詳しくは前章のレイアウトを確認してください。

38.2.2 図のキャプションやコード表示の指定：fig-cap/echo

chunk optionには、出力される図（グラフなど）のキャプション（fig-cap）、図を読み出すことが出来ないときに表示されるテキスト（fig-alt）などを設定することもできます。また、以下のようにecho: fencedを設定すると、表示されるコードにchunkが付いた形で表示されます。

様々なchunk optionの設定
```{r}
#| filename: "様々なchunk optionの設定"
#| fig-cap: "figure caption：出力した図にキャプションが付く（cap-location: marginなので右に表示）"
#| fig-alt: "図が読みだせません"
#| fig.height: 4
#| cap-location: margin

# fig-altは図が表示されない場合に表示されるテキストのこと。
# Rではよほど大きいファイルを取り扱わない限り必要ないかと思います。
# #| echo: fenced を設定しているので、chunkが表示されています
#（#| echo: fencedででは表示されません）
# cap-locationはmarginにfig-capを置くためのoptionです。
 
plot(cars)
```

また、echo:fencedの代わりに、括弧を2重（{{}}）にすることでもchunkを表示させることができます。この方法では他のオプションを指定しにくいため、echo:fencedを用いた方がよいでしょう。

カッコを2重にする
```{r}
1 + 1
```

38.2.3 出力の表示方法の変更：results: asis

results: asisはchunkの演算結果を通常の結果の表示方法ではなく、Markdownとしてそのまま出力するためのオプションです。以下の例のように、cat関数の返り値は通常文字列の返り値として、以下のように表示されます。

通常の出力
```{r, filename = "通常の出力", echo="fenced"}
cat("[マークダウン](https://daringfireball.net/projects/markdown/)を**そのまま**表示する\n")
```
[マークダウン](https://daringfireball.net/projects/markdown/)を**そのまま**表示する

results: asisを設定すると返り値が通常のMarkdownとして取り扱われ、リンクや太字の表示がMarkdownに従い変換されます。使いどころは難しいのですが、Rの出力の表示を変えたいときには使うことがあるかもしれません。

results: asis
```{r, echo="fenced", filename = "results: asis"}
#| results: asis

cat("[マークダウン](https://daringfireball.net/projects/markdown/)を**そのまま**表示する\n")
```

マークダウンをそのまま表示する

38.2.4 図を複数列に並べて表示する：layout-ncol

また、layout-ncolを用いることでRの出力するグラフを2列に並べることもできます。

layout-ncolでグラフを横に並べる
```{r, echo = FALSE}
#| layout-ncol: 2

plot(cars)
ggplot(iris, aes(x = Sepal.Length, y = Sepal.Width, color = Species)) + geom_point(size=2)
```

38.2.5 コードの表示を折りたたむ：code-fold/code-overflow

また、コードを折りたたむ場合にはcode-fold: true、長いコードを折り返し表示したい場合にはcode-overflow: wrapを指定します。

code-foldとcode-overflow
```{r}
#| echo: fenced
#| code-overflow: wrap
#| code-fold: true

print("Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt ut labore et dolore magna aliqua. Ut enim ad minim veniam, quis nostrud exercitation ullamco laboris nisi ut aliquip ex ea commodo consequat.")
```

38.2.6 コードの行に番号を付ける：code-line-numbers

code-line-numbersはコードの行に番号をつけるためのオプションです。trueに指定することで、コードの行の頭に数字が付きます。後で説明するcode annotationという機能よりは簡潔に行数を表示し、説明しやすくすることができます。

code-line-numbers
```{r, filename = "code-line-numbersを指定する"}
#| code-line-numbers: true

a <- 1
b <- 2
a + b
```
code-line-numbersを指定する
a <- 1
b <- 2
a + b
[1] 3

38.2.7 実行結果をキャッシュする：cache

cache（キャッシュ）とは、演算結果を保存しておくことで、コードを書き換えない時には以前に保存した結果を、コードを書き換えた時には新たな演算を実行するための、chunkの機能のことです。計算が重いchunkではcache:trueと設定しておくと、Renderするときにかかる演算の時間を省略できます。

cacheの設定
```{r}
#| cache: true

replicate(1000000, rnorm(1)) |> head()
```
cache:trueを指定
replicate(1000000, rnorm(1)) |> head()
[1]  0.4020361 -1.0432694  1.1943262  1.3362421 -0.8965265 -0.4314073

38.3 code annotation

code annotationとは、実行するRコードの行に番号を付け、その番号を引用して説明文を加えることができる、chunkの機能のことです。このテキストのように、コードの内容を説明するときに使用すると、わかりやすい文を作成することができます。

code annotationを用いる場合には、コードの行に# <1>などの数値を加え、chunkの下に箇条書き（1. XXXなど）を記載します。箇条書きの数値の記載と、# <1>の数値が対応し、コードと箇条書きの両方に同じ形の番号が示されます。

code annotation
```{r}
library(palmerpenguins)
penguins$species |> levels() # <1>
penguins |> group_by(species) |> summarise(mean_bm = mean(na.omit(body_mass_g))) # <2>
```

1. penguinsには3種のペンギンのデータが含まれる
2. ジェンツーペンギンは一回り大きい
library(palmerpenguins)
1penguins$species |> levels()
2penguins |> group_by(species) |> summarise(mean_bm = mean(na.omit(body_mass_g)))
1
penguinsには3種のペンギンのデータが含まれる
2
ジェンツーペンギンは一回り大きい 
[1] "Adelie"    "Chinstrap" "Gentoo"   
# A tibble: 3 × 2
  species   mean_bm
  <fct>       <dbl>
1 Adelie      3701.
2 Chinstrap   3733.
3 Gentoo      5076.

説明文と返り値の位置など、調整がやや煩雑なのでこのテキストではcode annotationは用いていません。

temp <- rnorm(1)

次に、以下のように、{r}で囲い、Markdownの文中に記載することで、その文中のRのコードを実行することが出来ます。

インラインコード

### 実行結果をキャッシュする：cache

[cache](https://ja.wikipedia.org/wiki/%E3%82%AD%E3%83%A3%E3%83%83%E3%82%B7%E3%83%A5_(%E3%82%B3%E3%83%B3%E3%83%94%E3%83%A5%E3%83%BC%E3%82%BF%E3%82%B7%E3%82%B9%E3%83%86%E3%83%A0))（キャッシュ）とは、演算結果を保存しておくことで、コードを書き換えない時には以前に保存した結果を、コードを書き換えた時には新たな演算を実行するための、chunkの機能のことです。計算が重いchunkでは`cache:true`と設定しておくと、Renderするときにかかる演算の時間を省略できます。

````{markdown, filename="cacheの設定"}
```{r}
#| cache: true

replicate(1000000, rnorm(1)) |> head()
```
````

```{r, filename="cache:trueを指定"}
#| cache: true

replicate(1000000, rnorm(1)) |> head()
```

## code annotation

code annotationとは、実行するRコードの行に番号を付け、その番号を引用して説明文を加えることができる、chunkの機能のことです。このテキストのように、コードの内容を説明するときに使用すると、わかりやすい文を作成することができます。

code annotationを用いる場合には、コードの行に`# <1>`などの数値を加え、chunkの下に箇条書き（`1. XXX`など）を記載します。箇条書きの数値の記載と、`# <1>`の数値が対応し、コードと箇条書きの両方に同じ形の番号が示されます。

````{markdown, filename="code annotation"}
```{r}
library(palmerpenguins)
penguins$species |> levels() # <1>
penguins |> group_by(species) |> summarise(mean_bm = mean(na.omit(body_mass_g))) # <2>
```

1. penguinsには3種のペンギンのデータが含まれる
2. ジェンツーペンギンは一回り大きい
````


説明文と返り値の位置など、調整がやや煩雑なのでこのテキストではcode annotationは用いていません。
